**Asistente BDCC**

Chatbot basado en reglas para responder consultas sobre Black Desert Combat Club. Desarrollado con Python y NLTK para el Avance de proyecto 1.

*Funciones*
- Información sobre juegos y actividades.
- Orientación sobre inscripción, costos y contacto.
- Contexto básico entre mensajes y manejo de consultas no reconocidas.

*Ejecución*

Abre BDCC_Avance_1.ipynb en Google Colab y ejecuta las celdas en orden. Para conversar con el chatbot, cambia MODO_INTERACTIVO = True en la última celda.

*Pruebas*

La celda %run pruebas.py ejecuta diez conversaciones y genera los resultados. La evaluación de referencia obtuvo 22 clasificaciones correctas de 23 mensajes.

*Alcance*

Prototipo informativo: no realiza inscripciones ni pagos y no consulta información en tiempo real.
